# SKY PEDAL — 空とぶ自転車

丘をかけ下りて、空へ。
**雲海 → 空の街 → 夕陽の海 → 星の海**をこえて、**月**まで。
指一本で飛べる、スマホ最優先の 3D フライトゲームです（ビルド不要・外部画像/音声ファイルなし）。

「スラスト・ロードスター」シリーズ（[Game_fly_car](https://github.com/cuichunxue/Game_fly_car) / [Game_fly_car_cliff](https://github.com/cuichunxue/Game_fly_car_cliff) / [Game-fly-car-jump](https://github.com/cuichunxue/Game-fly-car-jump)）の
描画・ポストFX・音声合成エンジンを受け継ぎ、**レーンを走るゲームから「空を自由に飛ぶゲーム」へ**作り直しました。
設計の考え方は [DESIGN.md](DESIGN.md) にまとめています。

## 遊び方
`index.html` をブラウザで開くだけ。ローカルでは簡単なサーバー経由がおすすめです：`npx http-server .`
HTTPS で公開すると、ホーム画面に追加してフルスクリーン＆オフラインでも遊べます（`manifest.webmanifest` / `sw.js`）。

| 操作 | スマホ | キーボード | ゲームパッド |
|---|---|---|---|
| 操縦（のぼる・さがる・まがる） | 画面のどこでも**なぞる**（指を置いた所がスティックの中心） | ← → ↑ ↓ / WASD | 左スティック・十字 |
| こぐ（加速・上昇） | 右下の **こぐ** を長押し | Space / Shift | A / RT |
| ベル（鳥を呼ぶ） | 🔔 | B / Enter | X / Y |
| 一時停止 | II | P / Esc | Start |

- **指をはなすと水平にもどる**。こぐのは上るときだけでいい（元気ゲージは滑空・上昇気流で回復）。
- 下ると速く、上ると遅くなる。**高さとスピードを交換する**のがコツ。速すぎず遅すぎず。
- **光の輪**をつなげてコンボ。ラインの最後の**金の輪**で追い風。全部くぐれば PERFECT。
- **上昇気流**（きらめく渦）に入ると、手をはなすだけでぐんぐん上がる。
- 鳥の群れに近づくと**なかま**になってV字で一緒に飛ぶ（得点アップ）。ベルで遠くの群れも呼べる。
- 各世界に **★スターメダル** が3つ。雲の中、橋の下、滝の裏、波すれすれ…。
- 設定：アシスト（つよい／ふつう／なし）、上下反転（飛行機式）、**スマホを傾けて操縦**、揺れ・フラッシュ控えめ、BGM/効果音の音量、画質（自動調整あり）。

### のりもの（4台）
タイトル画面の 3D の自転車の下にある **‹ ›** で切りかえ。まだ乗れない車体も見られます（🔒 と解放条件を表示）。

| のりもの | 変形 | 解放条件 |
|---|---|---|
| 🪽 はねの自転車 | 羽がひらく。こぐと羽ばたく | 最初から |
| 🚁 変形フライバイク | 車輪の横にたたんだ4つのダクトファンが、離陸で横に展開 | 空の街に着く |
| 🛞 ホバーバイク | 2つのタイヤが倒れてファンになる | ★を6個集める |
| 🐕 カーゴバイク | ファン展開＋前のカーゴに相棒の犬。リングやベルで吠えてしっぽをふる | 月に着く |

飛び方の性能は4台とも同じ（バランスをくずさないため）。違うのは見た目・変形演出・音（羽ばたき／モーターとファンの音）・光の軌跡。
ファンはペダルの力で回る設定なので、「こぐ」の意味はそのまま残ります。新しく乗れるようになるとリザルト画面に「のってみる」が出ます。

### モード
- **ジャーニー**：朝の丘から月まで約4〜5分の旅。到達した世界から再挑戦できる。
- **そらさんぽ**：点数もライフも気にせず、好きな世界をどこまでも飛ぶ。

## 構成
```
index.html          画面・HUD・タッチ操作
css/style.css       UI（スマホ縦・横／デスクトップ、セーフエリア対応）
js/textures.js      Canvas による手続きテクスチャ（草・岩・壁・羽根・月・雲）
js/models.js        自転車＋ライダー（ペダルに追従する脚のIK）・羽・マフラー・鳥・浮島・塔・飛行船・灯台・クジラ・月／静的メッシュの結合（bake）
js/audio.js         Web Audio 合成：風・ペダル・フリーホイールの「チチチ」・羽ばたき・ベル・効果音・世界ごとのメロディ付きアダプティブBGM
js/world.js         5つの世界の空・雲海・海・離陸の丘・積雲、コース計画（データ）と近傍生成、当たり判定
js/fx.js            パーティクル・スピードライン・翼端の光跡・上昇気流・水しぶき・花火・浮遊物・足元の影
js/game.js          飛行物理・入力・カメラ演出・進行・スコア・なかまの鳥・記念写真とシェア・HUD
js/vendor/          three.js r147（MIT）
sw.js / manifest    オフライン対応・ホーム画面追加
DESIGN.md           分析・TRIZ・ジャーニーマップ・エンパシーマップ・検証記録
```
