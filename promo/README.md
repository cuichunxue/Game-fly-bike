# SKY PEDAL — 30秒プロモ動画

縦型 1080×1920・30fps・30秒（TikTok / YouTube ショート / Instagram リール向け）。
**すべて実際のゲーム画面**を、テスト用フックで1フレームずつ決定論的に進めて撮影し、
BGM・効果音もゲーム本体の音声エンジン（`js/audio.js`）をオフラインで鳴らして作っています。

| 秒 | ショット | テロップ |
|---|---|---|
| 0–6.5 | 丘を下って崖から離陸、羽がひらく → ロゴ | 丘の先は── / 空だった。 |
| 6.5–10.5 | 雲海で光の輪をつなぐ（HUD・指の操作を表示） | 指1本で 自由に飛べる。 |
| 10.5–14.5 | 4台の変形（羽・フライ・ホバー・カーゴ＋犬） | 4台の 空とぶ自転車 |
| 14.5–18.5 | 浮島の街、橋の下をくぐる | 浮島の街を くぐり抜けて。 |
| 18.5–22.5 | 雲を突き抜けて夕陽の海、岩のアーチ | 雲を突き抜けて── / 雲の下は 夕陽の海。 |
| 22.5–30 | 月の門 → 月の前を横切るシルエット → エンドカード | そして── / 月まで、とどけ。 |

## 作り直し方
```sh
npx http-server -p 8123 .                       # ゲームを配信
node promo/capture.js WORK --from 0 --to 434 &   # 撮影（ショット単位で分割・並列可）
node promo/capture.js WORK --from 435 --to 899
promo/build.sh WORK                              # BGM生成＋エンコード → WORK/sky-pedal-promo-30s.mp4
```
`--preview` で低解像度の確認撮影、`--step N` で間引き。Playwright と ffmpeg（libx264）が必要です。
エンドカードのURL（cuichunxue.github.io/Game-fly-bike）は GitHub Pages を公開した場合のものです。
